# Security reporting

safeclone 0.1.0 is experimental. Read the [security model](docs/security-model.md)
and [supported environment](docs/support.md) before using it. Detection and
verification do not establish that a workspace is safe to disclose.

Do not disclose security vulnerabilities in public issues. **GitHub Private
Vulnerability Reporting is enabled** for
[matgusa/safeclone](https://github.com/matgusa/safeclone).
Use [Report a vulnerability](https://github.com/matgusa/safeclone/security/advisories/new)
in the repository's [Security advisories](https://github.com/matgusa/safeclone/security/advisories)
section. A GitHub account and sign-in are required to submit a private report.

Do not put secrets, original/private workspaces, sensitive paths, private session
artifacts or confidential exploit details in public issues or logs. Keep any
reproduction synthetic and avoid including the affected data itself.
